## 〇、一句话结论

1. 你们的技能表整体结构是 **Monster Survivors（下称 MS）的「主动技能 + 被动技能 → 进化技能」换皮**，11 个主动 + 11 个被动 + 11 个进化（目前只有 201 填了）。我按 MS 的「每把武器满级 + 一个被动 = 进化」规则，把 202–211 全部补齐（见第三节）。
2. 但表格存在两类要命的问题：**（a）表内数据自相矛盾/笔误**；**（b）表格还在用 MS 的「倍率」口径，而游戏实际代码已经改成「D 基准」口径（D=1 基础伤害、敌人 HP 只有 1~34），两套口径不能直接混用**。详见第五节。

## 二、进化规则（与 MS 对齐）

MS 的规则（图鉴「进化配方」节）：**基础技能满级 + 配套被动 ≥ Lv1 → 进入升级候选池；进化后移除基础技能、保留被动；进化技能固定 1 级。**

vessel 沿用此规则即可，唯一要注意的是触发阈值不能用死「Lv5」：因为 止血夹(1005)、弹簧圈(1006)、抽吸导管(1007) 目前上限只有 3 级，所以统一写成「**基础技能满级** + 配套被动 ≥ Lv1」更安全（详见 5.3）。

## 三、进化技能设计（202–211）

命名沿用「医疗器械/治疗流程」主题，数值参照 MS 对应进化的缩放幅度（进化伤害 ≈ 基础满级的 1.2~2 倍 + 新增机制）。**⚠ 下列伤害是 MS 口径的「倍率」，接入当前 D 基准代码前需按第五节换算。**

### 202 超声解剖剪 ← 解剖剪满级 + 深耕科研 Lv1
- **类别**：近战挥砍　**伤害**：40　**数量**：6（剪刃）　**半径**：4.6　**角度**：130°　**弹速**：12　**周期**：1.5 秒
- **特殊**：剪刃不再只贴身，而是高速飞射并滞留旋转，持续切割路径敌人；命中后按十字交叉补第二剪（42°）。
- **设计理由**：解剖剪本身是「接触伤害」的近战，进化方向取「深耕科研（弹速）」→ 由近战升级为「剪刃飞出」的远程，弥补它手短的短板（对应 MS 狼牙球那种「近战→更猛+击退」的思路）。

### 203 血液回收钳 ← 侧壁钳满级 + 心形护符 Lv1
- **类别**：吸血　**概率**：0.5　**回复**：8% 最大生命　**溢出治疗 → 护盾**
- **特殊**：概率 0.5 回 8% 最大生命；溢出部分转化为临时护盾。
- **设计理由**：吸血按「最大生命百分比」结算，搭「心形护符（最大生命）」是天然乘法；「溢出转护盾」是医学上「自体血回输」的意象，也让吸血在高血量时不过度浪费。

### 204 吻合钉枪 ← 缝线满级 + 覆膜支架 Lv1
- **类别**：穿透　**伤害**：30　**数量**：5　**弹速**：12　**尺寸**：0.75
- **特殊**：发射多根高速穿透缝合钉。
- **设计理由**：缝线 = 冰晶（穿透弹）的换皮，直接对齐 MS「冰晶 + 泰坦盾 → 银桩」。覆膜支架（减伤/护盾）→ 吻合钉枪，也是「外科缝合器械」的进阶。

### 205 栓塞止血网 ← 止血夹满级 + 吸液管 Lv1
- **类别**：区域　**伤害**：D（由 D÷2 提升）　**半径**：2.6　**持续**：2 秒　**tick**：0.2 秒
- **特殊**：击杀区域扩大且持续翻倍，并把周围敌人吸入区域。
- **设计理由**：止血夹是「击杀留区域」，搭「吸液管（磁吸/吸引）」把敌人拉进区域，形成「止血 + 吸引」的连锁控场。

### 206 血管痉挛环 ← 弹簧圈满级 + 参与重大手术 Lv1
- **类别**：减速　**伤害**：15　**半径**：1.75　**减速**：50%（移速 ×0.5）　**tick**：1 秒
- **特殊**：形成持续减速场并造成范围伤害。
- **设计理由**：弹簧圈（减速）是 MS「时间之眼（守护之眼 + 沙漏）」的机制来源，这里对齐「减速 50% + 范围伤害」。医学上「血管痉挛」正是弹簧圈栓塞的并发症意象。

### 207 体外循环泵 ← 抽吸导管满级 + 快乐水 Lv1
- **类别**：激光　**伤害**：D（由 D÷2 提升）　**跟随物**：3　**激光长**：6、宽 0.25　**间隔**：0.6 秒
- **特殊**：多个跟随物同时发射更强激光，命中回血（吸血）。
- **设计理由**：抽吸导管（浮游炮激光）≈ MS 太阳聚光器（光束），对齐「光束 + 活力药水 → 月光投射器」。「抽吸 + 补液/回血」= 体外循环（心肺转流）的医学意象。

### 208 定向消融弹雨 ← 消融弹满级 + 义诊科普 Lv1
- **类别**：炸弹　**伤害**：30　**数量**：4　**爆炸半径**：1.8　**冷却**：6 秒　**间隔**：0.5 秒
- **特殊**：从上方投下多枚消融弹并产生范围爆炸。
- **设计理由**：消融弹 = 火球换皮，对齐 MS「火球 + 成长豆 → 陨石」（天上落弹雨）。

### 209 高频电刀 ← 手术刀满级 + 进修培训 Lv1
- **类别**：近战挥砍　**伤害**：30　**连续挥砍**：5　**电弧刀波伤害**：5　**半径**：4.5　**角度**：170°　**尺寸**：1.4
- **特殊**：连续挥砍并发出电弧刀波；刀身与刀波分别结算。
- **设计理由**：手术刀 = 钢剑换皮，对齐 MS「钢剑 → 神圣之刃」。MS 用「金币」被动（vessel 没有），这里用「进修培训（伤害）」替代，更贴合近战输出定位。

### 210 微量输液泵 ← 针头子弹满级 + 对口支援 Lv1
- **类别**：远程锁敌　**伤害**：15　**冷却**：0.2 秒　**弹速**：10　**数量**：2
- **特殊**：以极短冷却持续发射强化针头。
- **设计理由**：针头子弹 = 木杖换皮，对齐 MS「木杖 + 智慧之书 → 远古权杖」（伤害略降但射速暴涨，DPS 反而大幅提升）。

### 211 雾化给药机 ← 安瓿瓶满级 + 快速处置 Lv1
- **类别**：炸弹　**伤害**：30　**数量**：5　**爆炸半径**：2.8　**药剂池**：最多 3 滩（半径 2.6、持续 5 秒）　**移速 ×1.15**
- **特殊**：投掷频率提升，落地多滩药剂池，并附加移速。
- **设计理由**：安瓿瓶是药剂师基础攻击（范围炸弹 + 药剂池），搭「快速处置（移速）」（安瓿瓶 R1 本身就加移速）收束成「给药 + 机动」的一体进化。

### 5.2 口径冲突：MS「倍率」 vs 游戏「D 基准」（最关键）

- MS 图鉴明确写：**实际伤害 = 角色 Damage × 技能倍率**，主动倍率 5~50。
- 你们当前 `balance.csv` 是另一套：**D = `attack.bullet_damage` = 1**，技能伤害是 `D`、`D+1`、`D+2`、`D÷2`（如 手术刀 D+1、消融弹 D+2、止血夹 D÷2）。
- 而敌人血量只有 **细胞阴影 HP1、尖刺士兵 HP3、Boss HP34**（MS 的南瓜怪 HP45、吸血鬼 HP120）。

**后果**：如果直接把表格里的 MS 倍率（冲洗针 5、缝线 20、消融弹 15、手术刀 10、针头子弹 10、安瓿瓶 20，以及我上面给的进化 15~40）当数值塞进 D=1 的世界，一刀就能秒一片、Boss 两秒蒸发。**这套倍率不能直接落地。**

建议：统一到 D 基准。例如把「伤害 35」改写成 `D×35` 前，先重新锚定——当前 D=1、DPS=2/秒（间隔 0.5），敌人 HP 1~34，那么：
- 普通主动技能伤害定位在 `D ~ D+3`；
- 进化技能定位在 `D×2 ~ D×5` 或 `D+5~D+10`；
- 需要先跑一局验证「击杀节奏主轴」（见 `主轴公式` sheet：玩家DPS=2/秒 → 细胞阴影 0.5 秒/只）。

### 5.3 等级数不统一（会卡住进化）

- 表格里 止血夹/弹簧圈/抽吸导管 上限是 **3 级**，其余主动是 5 级；被动全是 3 级。
- MS 所有技能都是 5 级，进化阈值是「Lv5 + 被动 Lv1」。你们一旦照抄「Lv5 才进化」，这 3 个技能永远无法进化。
- 当前代码（`VesselSkillCatalog.cs`）已经把所有通用技能统一成 **3 级**、只有三个角色武器是 5 级（Rank R0–R5）。**两处口径对不上**：要么把表格也统一成 3 级，要么把代码里的 3 级改回 5 级，并让进化判定用「满级」而不是写死「Lv5」。

### 5.4 被动被压缩成 3 级，几个关键被动被砍狠了

MS 被动是 5 级、vessel 只有 3 级，直接丢掉后两档。最伤的是：

| 被动 | MS 满级 | vessel 满级 | 影响 |
|---|---|---|---|
| 吸液管（磁吸） | ×6（半径 3→18） | ×1.3（3.5→4.55） | 磁吸几乎无效，后期捡经验会很难受 |
| 心形护符（生命） | ×2.0 | ×1.6 | 少了 20% 血，后期猝死风险↑ |
| 参与重大手术（冷却） | ×0.6（减 40%） | ×0.76（减 24%） | 冷却收益腰斩 |
| 覆膜支架（减伤） | 加算 50% | 乘算 0.65（=35%）+护盾再生 | 模型都变了，不是简单缩水 |

其余（伤害/弹速/尺寸/移速/经验/时长）也从 MS 的 ×1.5 缩到 ×1.3。整体等于**把 MS 的成长曲线砍掉 40%~60%**，需要对应调低敌人成长或调高基础值，否则后期会「技能升满但打不动」。

### 5.5 敌人血量/伤害基准完全不同，别照搬 MS 的关卡节奏

- MS 小怪 HP 8~120、接触伤害 3~15；vessel 小怪 HP 1~12、接触伤害 **20~60**。
- 也就是说 vessel 是「低血量、高伤害」的世界：敌人摸你一下 = 你血量的 1/5~1/2（血量 100，挨 2.5~5 下就倒），而 MS 是「高血量、低伤害」。
- 所以 MS 里「慢慢磨、靠 50% 减伤+回血拖」的节奏，在 vessel 里行不通；vessel 的生存更依赖**走位、击退、减速、吸血**这类主动规避，而不是堆减伤硬扛。这条要贯穿到进化数值里：**进化技能优先给「控场/机动/吸血」，而不是无脑堆伤害**（这也正是我上面 205/206/207/211 都往控场靠的原因）。

### 5.6 其它注意

- **金币体系被删**：MS 有 黄金圣杯（金币被动）+ 金币满级奖励（40 金币）。vessel 没金币，所以 MS 的「钢剑+金币→神圣之刃」这条配方必须换被动（我已换成 进修培训/伤害）。
- **满级奖励**：MS 全技能满级后给「治疗 40%」或「金币」。vessel `balance.csv` 只有 `game.maxed_skill_heal_percent = 0.1`（10% 回血），没有金币选项。如果做了进化系统，满级/进化后的「可选项耗尽」兜底需要重新设计（否则升满后卡升级界面）。
- **进化后移除基础技能**：MS 是「进化后移除基础武器、保留被动」。但你们三个角色武器（手术刀/针头子弹/安瓿瓶）是**天赋武器、随角色 Rank 进化**，不能像 MS 那样「被移除」——否则角色就没了基础攻击。建议：角色武器的进化做成**Rank 路线内的形态变化**（R5 已经这么写了），只有 8 个通用技能走「技能+被动→进化」这条 MS 式路线。
