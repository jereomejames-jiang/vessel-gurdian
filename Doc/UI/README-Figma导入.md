# Figma 起始文件使用说明

这个文件是给你"照着改"的线框，不是最终设计稿。里面已经按游戏的真实尺寸摆好了主菜单和一套基础规范，你不需要从空白画布开始。

## 三步导入

1. 打开 figma.com，登录，新建一个 Design file（免费版够用）。
2. 把 `VesselGuard_UI_Starter.svg` 直接拖进画布中间。
3. 左侧图层面板里会出现两个组：`Screen/MainMenu`（主菜单）和 `Foundations`（色板/字号/按钮状态）。

导入后是一个 3000×1080 的大画板。想拆成两个独立画板：选中 `Screen/MainMenu` 这个组 → 右键 → **Frame selection**（快捷键 `Cmd+Opt+G`）。

## 第一件要做的事：换字体

导入后如果提示字体缺失，或者中文变成方框：

1. 点进 `Screen/MainMenu`，按 `Cmd+A` 全选。
2. 右侧 **Text** 面板 → 字体选 **Noto Sans SC**。

`Foundations` 里也做一遍。之后所有文字都会正常。

## 文件里有什么

**Screen/MainMenu**（1920×1080，对应游戏主菜单）

| 图层名 | 是什么 |
|---|---|
| `bg/sky` | 背景渐变 |
| `Card/face` | 白色圆角卡片，900×760，圆角 56 |
| `Title/zh` `Title/en` `Title/tagline` | 标题三行 |
| `btn/primary/L` | 主按钮，500×104 |
| `btn/secondary/M-1..3` | 次级按钮，240×76 |
| `btn/tertiary/S-1..3` | 辅助按钮，188×60 |
| `Version` | 版本/状态文字 |
| `GUIDE/SafeArea-64` | 粉色虚线安全区，**导出前隐藏或删掉** |

按钮是三个图层叠出来的：`depth`（底部深色边）+ `face`（正面）+ `label`（文字）。改颜色时改 `face` 和 `depth` 两个。

**Foundations**（右边那块）

- 8 个颜色样式（名称、色值、用途都写在旁边）
- 3 个字号示例
- 按钮的默认 / 悬停 / 按下三种状态

## 怎么改

- 改颜色：选中形状 → 右侧 **Fill**。
- 改文字：双击文字层直接编辑，右侧调字号和字重。
- 改圆角：选中矩形 → 右侧 **Corner radius**。
- 复制一个按钮：选中按钮组 → `Cmd+D`，再改宽度和文字。

## 什么时候需要新建组件

先别建。等你把主菜单改到满意，再选中一个按钮 → `Cmd+Opt+K` 变成组件，然后右键 → **Add variant** 做悬停/按下。组件是给"反复用"的东西，一开始就建容易返工。

## 改完怎么交给我

1. 选中 `Screen/MainMenu` → 右侧最下面 **Export** → `+` → 选 **PNG**、**1x** → Export。得到 1920×1080 的效果图。
2. 如果里面有你自己画的图案、边框、图标，单独选中它 → Export → **PNG 2x**，透明背景。
3. 把图发我，并说一句"这就是我想要的样子"。

我拿到图之后会在 Unity 里按同样布局重建，渲染一张 1920×1080 的预览发你对比，你指哪儿不对我改哪儿。

## 注意

- 文字不要合并进图片，导出时让文字保持独立，否则游戏里改不了数值。
- 不要加模糊阴影、外发光、文字描边——Unity 的 UI 没有这些效果，加了也还原不了。
- 安全区（粉色虚线）只是参考，最终导出前记得隐藏。
